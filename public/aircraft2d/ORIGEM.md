# Origem do acervo 2D

Fonte única: `Sistema Aeronaves 2D.zip`, fornecido pelo usuário para esta integração.

SHA-256 do ZIP: `353c0d11a1a72db817435ada485b34fd774046092ca755cb66a720f84cd8b401`.

Os recursos desta pasta foram extraídos do arquivo fornecido. Não são imagens geradas pelo Skyline ou obtidas da Wikimedia Commons. A deduplicação mantém os bytes originais; `inventory.json` relaciona cada origem a seu destino e hash. Nomes de arquivos, logos, fontes e imagens conservam a procedência do acervo. Não foi identificada uma licença única no arquivo que permita atribuir MIT/Creative Commons ao conjunto; a licença do código do projeto não é uma nova licença destes recursos.

Os módulos Hermes, executáveis, repositórios de ferramentas e scripts contidos no ZIP não são distribuídos como código executável do jogo.
